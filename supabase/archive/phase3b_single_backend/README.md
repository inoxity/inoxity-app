# Archived Phase 3B single-backend SQL

These files represent the original single-backend Phase 3B design. They are preserved only for historical reference and must never be applied to a new Inoxity V2 deployment.

That design placed study configuration, participant enrollment, and withdrawals in one Supabase project. It was replaced before live deployment by the active control-backend/Study-Backend architecture under `supabase/control_backend` and `supabase/study_backend_template`.

The archive is intentionally not referenced by active migrations, verification scripts, or setup instructions.
